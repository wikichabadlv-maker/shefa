# שפע של עשייה

אפליקציית אייפון נייטיבית (SwiftUI) לניהול הבית: פיננסים, לו״ז, מטלות, לימוד, קניות ועוזר אישי.

| תיקייה | מה יש בה |
| --- | --- |
| `sync/` | מנוע הסנכרון: מושך תנועות מדיסקונט, מקס וכאל (ספריית israeli-bank-scrapers) |
| `supabase/` | מבנה מסד הנתונים המשותף |
| `.github/workflows/` | הרצת הסנכרון בענן של GitHub |

## הזנת פרטי הגישה לבנק (פעם אחת)

הסיסמאות נשמרות רק בכספת המוצפנת של GitHub. אף אחד, כולל מי שכתב את הקוד, לא יכול לקרוא אותן אחרי השמירה. הן לא מופיעות ביומני הריצה.

1. במאגר: **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**.
2. לכל שורה בטבלה: ב-**Name** מעתיקים את השם, ב-**Secret** כותבים את הערך, ולוחצים **Add secret**.

| Name | מה לכתוב |
| --- | --- |
| `DISCOUNT_ID` | תעודת זהות |
| `DISCOUNT_PASSWORD` | הסיסמה לאתר דיסקונט |
| `DISCOUNT_NUM` | קוד המשתמש (הקוד המזהה שמקבלים מהבנק) |
| `MAX_USERNAME` | שם המשתמש באתר מקס |
| `MAX_PASSWORD` | הסיסמה באתר מקס |
| `CAL_USERNAME` | שם המשתמש באתר כאל |
| `CAL_PASSWORD` | הסיסמה באתר כאל |

לכרטיס נוסף מאותה חברה (למשל של בת הזוג): `MAX_2_USERNAME` / `MAX_2_PASSWORD`, או `CAL_2_USERNAME` / `CAL_2_PASSWORD`.

## בדיקת חיבור

**Actions** ← **סנכרון בנקים** ← **Run workflow** ← **Run workflow**. אחרי כ-3 דקות לוחצים על הריצה ורואים שורה לכל חשבון: ✅ ומספר התנועות, או ❌ וסוג השגיאה. הסכומים ושמות בתי העסק לא מוצגים ביומן.
